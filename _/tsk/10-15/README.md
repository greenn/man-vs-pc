# Задания 15.10.2026 — man-vs-pc

Материалы для Cursor и подготовки графики.

## В каком порядке использовать
1. **[00-cursor-plan.md](00-cursor-plan.md)** — передать Cursor сначала; только план, без изменения кода, до согласования дизайн-референса.
2. **[01-cursor-prompt.md](01-cursor-prompt.md)** — актуальные правила, страницы, результаты, повтор участников, первая версия с двумя играми.
3. **[02-mini-game-contract.md](02-mini-game-contract.md)** — универсальное задание для подключения каждой мини-игры; применяется позднее, когда согласованы правила.
4. **[03-illustration-prompts.md](03-illustration-prompts.md)** — промпты для общей графики: фоновые сцены, титульный баннер, спрайт персонажей, награды и другие элементы.
5. **[04-game-sprite-catalog.md](04-game-sprite-catalog.md)** — 20 мини-игр, единый формат атласа и индивидуальные графические уточнения.

Предыдущая версия требований: `../10-14/`. Репозиторий и приложение: `man-vs-pc`.

## Принцип реализации
Сначала **план без кода**, затем согласование референса, отдельная вёрстка и общая оболочка **с двумя готовыми играми**. В каталоге показывать только реально доступные игры. Затем подключать остальные по одной.

Служебные файлы находятся только в `_/`; приложение не должно их загружать.
