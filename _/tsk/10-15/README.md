# Задания 15.10.2026 — man-vs-pc

Материалы для Cursor и подготовки графики.

## В каком порядке использовать
1. **[01-cursor-prompt.md](01-cursor-prompt.md)** — основной короткий промпт: страницы, переходы, настройки, результаты, первый этап вёрстки.
2. **[02-mini-game-contract.md](02-mini-game-contract.md)** — универсальное задание для подключения каждой мини-игры; применяется позднее, когда согласованы правила.
3. **[03-illustration-prompts.md](03-illustration-prompts.md)** — промпты для общей графики: фоновые сцены, титульный баннер, спрайт персонажей, награды и другие элементы.
4. **[04-game-sprite-catalog.md](04-game-sprite-catalog.md)** — 20 мини-игр, единый формат атласа и индивидуальные графические уточнения.

Предыдущая версия требований: `../10-14/`. Репозиторий и приложение: `man-vs-pc`.

## Принцип реализации
Сначала **сверстать по референсу отдельный дизайн-прототип** и подготовить переходы с заглушками. Затем переиспользовать вёрстку для приложения. Игровые механики — следующим этапом.

Служебные файлы находятся только в `_/`; приложение не должно их загружать.
