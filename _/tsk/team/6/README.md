# Команда «6 класс» — файл импорта

- [1015-1.json](1015-1.json) — **публичный обезличенный пресет**: 21 участник, уникальные ID и инициалы, поля `avatarId` и `disabled`.
- При первом открытии приложения, если нет ранее сохранённой команды, использовать этот пресет по умолчанию.
- Начальный статус `disabled` нужен для исключения участника из случайного выбора. Перед началом мероприятия на экране подготовки можно включить/выключить любого участника. Это не победа, не поражение и не ничья.
- У каждого участника — ручной выбор человеческого аватара из атласа 30 персонажей (слот 0 зарезервирован за компьютером); сохранять `avatarId` вместе с ID.
- После выбора и настройки состава — кнопка «Игра». Действует только текущий список активных участников.

## Конфиденциальность

Репозиторий публичный, поэтому в нём сохранены только инициалы без полных имён и без причин отсутствия. Приложение должно поддерживать **локальный импорт полного JSON через выбор файла в браузере**. Не публиковать полные школьные списки и не включать их в клиентский бандл. После импорта данные сохраняются локально в браузере.

Папка `_/` служебная, недоступна приложению в runtime. При необходимости Cursor копирует только **обезличенный** JSON-пресет в разрешённую папку данных сборки (не личные сведения). При импорте версии команды сохранять привязку выбранных аватаров к стабильным ID.
