# pers-select — структура экрана выбора участника

**Проект:** «Человек против Компьютера» (`man-vs-pc`).  
**Тип документа:** структурный промпт для Cursor, без описания цветов и художественного стиля.  
**Иллюстрация:** `pers-select.dark-purple.png` (референс размещения блоков, не готовая вёрстка).

## Назначение
Показать весь шестой класс, разрешить выбрать ученика вручную или случайно, отключить временно отсутствующих и назначить аватары. После выбора перейти к представлению ученика **VS Компьютер**, а затем к выбору игры.

## Структура экрана
1. **Навигация приложения:** название, разделы «Главная», «Ученики», «Игры», «Статистика», «Достижения», «Настройки». Текущий раздел — «Ученики».
2. **Заголовок:** «Выбор ученика», число участников и короткая инструкция.
3. **Сетка участников:** разместить **все 21 карточку** в основной области на экране 16:9 (ориентир — 7 столбцов × 3 ряда, с адаптацией по ширине). Использовать пространство по высоте, не скрывать последние карточки без необходимости.
4. **Карточка:** порядковый номер/ID, выбранный аватар, **инициалы фамилии и имени**, признак доступности, признак текущего выбора. ФИО, если пользователь импортировал их локально, не публиковать вместе с макетом.
5. **Поиск и фильтр:** при необходимости поиск по инициалам и переключение «Все / Активные / Отключённые». При первом открытии показывать **всех**, включая отключённых.
6. **Панель выбранного ученика:** увеличенный аватар и инициалы, участие и статистика (сыграно матчей, побед, поражений, ничьих), возможность сменить аватар и `disabled`.
7. **Панель соперника:** отдельный аватар компьютера и обозначение VS; робот не входит в список учеников.
8. **Действия:** «Выбрать ученика», «Выбрать случайно», «Сменить аватар», «Включить / Отключить», «Продолжить» / «Начать игру», «Назад».

## Данные и состояния
- Начальные данные — обезличенный JSON `_/tsk/team/6/1015-1.json`: **21 участник, 4 изначально `disabled`**. Пресет помещать в runtime только в обезличенном виде, отдельно от служебной папки `_/`.
- `disabled` означает **не участвует в текущем выборе**; не начислять ни победу, ни поражение, ни ничью. Разрешить включать/отключать в любой момент подготовки.
- Аватары выбираются из атласа 30 персонажей: слот 0 — компьютер; остальные 29 — варианты для людей. Хранить `avatarId` за стабильным ID ученика; до генерации изображений показывать инициалы.
- Случайный выбор среди всех **активных** учеников. Уже игравшие могут выбираться повторно. Отдельно отслеживать тех, кто ни разу не играл, для условия завершения соревнования.
- Неактивного ученика нельзя запустить в матч, пока его не включат. Если активных нет, показать понятное состояние без возможности старта.
- Поддержать локальный JSON-импорт полного состава, не отправлять персональные данные в сеть; хранение в `localStorage`.
- После подтверждения выбора — переход «Ученик VS Компьютер», затем экран `game-select`.
- Интерфейс на **русском языке**. Элементы должны работать мышью и касанием.

## Граница документа
Не закреплять художественный стиль, цвета, свечения и декоративные решения. PNG — отдельный визуальный образец; здесь фиксируются состав блоков, содержание и логика.
