# Референсы экранов — man-vs-pc

Для каждого экрана дизайн хранится отдельно от структурного промпта:

```text
_/tsk/diz/
  game-select/1015/
    game-select.struct.md
    game-select.dark-purple.png
  pers-select/1015/
    pers-select.struct.md
    pers-select.dark-purple.png
```

- **[game-select](game-select/1015/game-select.struct.md)** — выбор мини-игры. Две карточки в первой версии, доступность из реестра реализованных игр.
- **[pers-select](pers-select/1015/pers-select.struct.md)** — выбор ученика. Полная сетка 21 участника, активность, выбор аватара.

Файлы `.struct.md` описывают **структуру и логику без художественного стиля**. PNG — визуальные референсы; суффикс в имени обозначает краткий стиль изображения, не обязательный шаблон CSS. В реализации все элементы должны быть реальной вёрсткой/интерактивными компонентами.

Изображения — **дизайн-макеты**, а не фактические данные: в них могут быть условные инициалы, имена, числа и демонстрационные результаты. Использовать данные команды и счёта из приложения, а не из картинки.
