# Human vs Computer

**man-vs-pc** — интерактивная игра «Человек против Компьютера» для занятий с классом и интерактивной доской.

Участники соревнуются с компьютерным соперником в одной из 20 мини-игр. Предусмотрены случайный или ручной выбор участника и игры, анимированные экраны VS, результаты, достижения и статистика.

## Состояние проекта

Проект находится на этапе проектирования интерфейса. Сначала создаётся **отдельная вёрстка по визуальному референсу**, затем на её основе — приложение. Правила и механики отдельных мини-игр будут уточняться позднее.

## Основные экраны

1. Титульная страница: импорт участников из JSON, инициалы, исключение участников, кнопка «Игра».
2. Выбор участника: ручной или случайный.
3. Представление пары «Человек VS Компьютер».
4. Выбор одной из 20 мини-игр: ручной или случайный.
5. Экран игры: аватары, VS, баннер, наглядные правила и игровая область.
6. Результат раунда / матча: победитель, достижения, переход к следующему участнику.
7. Итоговый экран победителей.
8. Статистика и достижения.
9. Настройки (в том числе число побед до завершения матча, по умолчанию **2**).

Хранение по умолчанию: **localStorage**. Возможность иных способов хранения оставляется для дальнейших этапов.
